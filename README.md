# Maragonesa Silveira | Advocacia Previdenciária

Landing page institucional do escritório Maragonesa Silveira — Advocacia & Consultoria, com foco em Direito Previdenciário, benefícios do INSS e atendimento especializado.

## Visão geral

Este projeto é uma website institucional desenvolvido em React com Vite, pensado para apresentar os serviços do escritório, transmitir confiança, reforçar a presença digital e facilitar o contato por WhatsApp e redes sociais.

## Stack tecnológica

- React 19
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- i18next para internacionalização

## Funcionalidades

- Layout responsivo para desktop, tablet e mobile
- Seções institucionais e de serviços
- CTAs para contato e WhatsApp
- Integração com vídeos e conteúdo de autoridade
- Suporte a múltiplos idiomas (PT, EN, ES)
- Design moderno com visual premium e institucional

## Requisitos

- Node.js 20+
- npm ou yarn

## Instalação

```bash
npm install
```

## Executando localmente

```bash
npm run dev
```

A aplicação fica disponível em `http://localhost:5173`.

## Build de produção

```bash
npm run build
```

## Preview da build

```bash
npm run preview
```

## Lint

```bash
npm run lint
```
