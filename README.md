# Maragonesa Silveira | Advocacia Previdenciária

Landing page do escritório **Maragonesa Silveira — Advocacia & Consultoria**, especializado em Direito Previdenciário e benefícios do INSS.

## Tecnologias

- **React 19** com Vite
- **Tailwind CSS v4** (via plugin Vite)
- **Framer Motion** para animações e parallax
- **Lucide React** para ícones

## Estrutura

```
src/
├── components/
│   ├── Header.jsx          — Header fixo com glassmorphism e menu mobile
│   ├── Hero.jsx            — Seção principal com parallax e CTA
│   ├── VideosSection.jsx   — Carrossel de vídeos YouTube com lazy loading
│   ├── ServicesSection.jsx — Cards de serviços em bento grid
│   ├── AboutSection.jsx    — Seção sobre com imagem e value cards
│   ├── ContactSection.jsx  — Contato com mapa e cards de WhatsApp/Email
│   ├── Footer.jsx          — Rodapé com CTA e redes sociais
│   ├── WhatsAppButton.jsx  — Botão flutuante do WhatsApp
│   └── WhatsAppIcon.jsx    — Ícone SVG reutilizável
├── assets/
│   ├── images/             — Imagens e thumbnails
│   └── fonts/              — TrajanPro Regular + Bold
├── App.jsx
├── main.jsx
└── index.css               — Theme, animações e utilitários
```

## Como rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
